How to Start the Calculator?

Here, you will learn how to start the calculator..

To use the calculator app, you need to unlock your phone first.

You can use a calculator app on your smartphone. You will find it useful, when you need to quickly calculate some numbers.

  1. Navigate to the Calculator application icon.
  2. Tap the icon.

The application starts.

You are now ready to calculate with it.

For example, if you have purchased a book for $5 and you have given $10, how much change should you expect?

The answer is 10-5 = $5 change.
