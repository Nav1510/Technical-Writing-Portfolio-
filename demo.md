******Collaboration and Version Control******

**Case 1** 
	**Action:** Remote file is not changed since the last pull.
	**Consequence:** Local file(s) remain the same regardless of the change.

**Case 2**
	**Action:** Remote file is changed but the local file is not changed.
	**Consequence:** Replaces remote file with the local file.

**Case 3**
	**Action:** Both remote and local files have changed.
	**Consequence:** Remote file is merged into the local file.
